WHAT EXISTS NOW
--------------------------------------------------
- 8 models: MenuItem, GalleryImage, Contact, Home, About, StaffMember,
  SiteSettings, AdminUser. Every content model has status; every list model has order.
- src/lib/prisma.ts — shared Prisma client (dotenv + PrismaPg, singleton)
- prisma/seed.ts — DESTRUCTIVE seed, manual only, never after launch
- prisma/create-admin.ts — non-destructive upsert, bcrypt 10 rounds
- auth.ts — Credentials provider, bcrypt compare, JWT sessions, 8h maxAge
- proxy.ts — guards /admin/* except /admin/login  (Next.js 16 renamed middleware.ts)
- src/lib/contentTypes.ts — THE REGISTRY: label, prismaModel, kind, hasOrder,
  hasStatus, listDisplayField, fields[] with input kind + requiredMessage
- src/components/FormMaker.tsx — draws any form from the registry
- src/components/ConfirmDialog.tsx — generic confirm/cancel modal
- src/components/ListRowControls.tsx — up / down / delete per row
- src/components/PublicNav.tsx — hides itself on /admin paths
- app/admin/actions.ts — one Server Action file for ALL types:
  saveContentItem, deleteContentItem, moveContentItem
- Admin routes (NO per-type page files):
  /admin (dashboard from registry) - /admin/[type] - /admin/[type]/new
  /admin/[type]/[id] - /admin/login
- 5 public pages unchanged, force-dynamic, PUBLISHED rows only
